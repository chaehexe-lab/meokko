# 머꼬

AI 기반 고객데이터 수집·세분화 및 꼬모냉장고 자동화 마케팅 시스템 구축 프로젝트

## 배포 링크

- [Meokko Insight 대시보드](https://meokko.vercel.app/dashboard-prototype/index.html)

## 데이터 갱신 구조

- 잠재고객·키워드·반응 데이터는 Vercel API를 통해 조회하며, GitHub Actions 배치가 매일 00:20(KST)에 주요 데이터 API를 호출해 최신 데이터를 재조회합니다.
- 기존고객 CRM 데이터는 스마트스토어센터의 최근 1년 성별·연령별 집계를 로컬 수집기로 갱신하며, 경쟁사 데이터는 현재 수집본을 사용합니다.

## 스마트스토어 기존고객 데이터 갱신

기존고객 카드의 UI는 유지하며, 숫자는 네이버 스마트스토어센터의
`데이터분석 > 고객현황 > 성별/연령별` 최근 1년 집계에서 생성합니다.

```bash
python scripts/sync_smartstore_customer_stats.py
```

- 최초 실행 시 전용 Chrome에서 판매자가 직접 로그인합니다.
- 이후 실행은 `data/raw/smartstore_customer_stats/chrome-profile/`의 로컬 로그인 세션을 재사용합니다.
- 신규구매고객과 재구매고객 수를 성별·연령별로 합산해 3개월, 6개월, 12개월 값을 생성합니다.
- 개인 고객의 이름, 아이디, 연락처, 주문번호는 수집하거나 저장하지 않습니다.
- 대시보드용 집계 결과는 `api/dashboard/crm-snapshot.json`에 저장됩니다.
- 로그인 세션과 네이버 원본 응답은 `data/raw/` 아래에만 저장되며 Git에 포함되지 않습니다.

## 프로젝트 목표☘️

꼬모냉장고의 국내 판매량 증가를 목표로, 시장 반응과 고객 데이터를 분석하여 핵심 타겟층을 도출하고 타겟별 마케팅 방향성을 제안하는 시스템을 구축한다.

프로젝트는 두 단계로 진행된다.

1. 시장 반응, 구매 저해 요인, 핵심 타겟층을 분석하는 STEP1 대시보드 개발
2. STEP1 분석 결과를 바탕으로 타겟별 홍보 채널과 마케팅 콘텐츠를 추천하는 STEP2 대시보드 개발

## 주차별 계획💫

| 주차 | 주요 계획 |
| --- | --- |
| 1주차 | 고모텍 현장 방문, 프로젝트 목표 설정, 전체 방향성 수립 |
| 2주차 | 꼬모냉장고 제품 분석, 국내 소형 냉장고 시장 조사, STEP1 대시보드 초안 설계 |
| 3~4주차 | 데이터 수집 후 시장 반응, 구매 저해 요인, 핵심 타겟층 분석 기능 개발 |
| 5주차 | 홍보 채널로 활용할 플랫폼 분석 및 STEP2 대시보드 초안 설계 |
| 6~7주차 | 플랫폼별 홍보 방식 구체화 및 AI 콘텐츠 추천 시스템 개발 |
| 8주차 | 프로토타입 시연, 최종 발표자료 제작, 운영 가이드 정리 |
